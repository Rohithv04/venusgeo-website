## ✨ Features

- **🎬 AI Brand Intro Video Loader & Scroll-Depth Morph**:
  - Fullscreen cinematic AI brand intro video loader at `scrollY = 0` with real-time video playback and HUD controls (`AI BRAND INTRO` live indicator, `Skip to Site` shortcut, `Scroll to explore` prompt).
  - Pinned GSAP ScrollTrigger timeline that scrubs and morphs the video card into the hero section's visual container based on scroll depth.
  - Floating production metric badges (`25+ Fleets & Enterprises`, `Contact Us` direct dial) that settle onto the video card as it docks.

- **💎 High-End Design & Satoshi Typography**:
  - Engineered according to clean, enterprise-grade aesthetics with subtle borders, generous white space, refined contrast, and tailored letter-spacing.
  - Full integration of Satoshi variable font for sharp, modern typography.

- **🏛️ 25+ Years Experience & Standard Badges**:
  - Dark charcoal dock card prominently featuring **25+ Years of Experience** in enterprise product-led engineering.
  - Compliance and standards ribbon covering SOC 2 Type II, HIPAA, Zero Trust, and ISO 27001.
  - Autonomous lifecycle control stage indicator (`Ingest → Process → Deploy`).

- **📦 Comprehensive Product & Engineering Ecosystem**:
  - Interactive product catalog: **E-commerce Posmate**, **Digital Twin DrQueues**, **PrivateID Decentralized Identity**, and **AI Document Studio**.
  - 4-Stage Product Lifecycle & Architecture workflow (`Discovery & Strategy`, `AI-Native Architecture`, `Zero-Trust Engineering`, `Continuous Evolution`).
  - Enterprise Mobility page (`/enterprise-mobility/`) detailing fleet management, native cross-platform mobility, IoT edge sync, and offline-first data sync.
  - Full enterprise stack strip (Microsoft .NET, AWS, Google Cloud, Azure, Kubernetes, NVIDIA AI, React, PostgreSQL).

- **📱 Flawless Responsiveness & Accessibility**:
  - Optimized for desktop (1440px+), laptop (1200px), tablet (900px), and mobile (390px).
  - Full keyboard accessibility, ARIA labels, semantic landmark elements, and `prefers-reduced-motion` compliance.

## 🚀 Getting Started

### Prerequisites
- Node.js 20.19+ or 22+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Rohithv04/venusgeo-website.git

# Navigate to directory
cd venusgeo-website

# Install dependencies
npm install
```

### Development
```bash
# Start local development server with HMR
npm run dev
```
Open `http://localhost:5173` to view the site.

### Production Build
```bash
# Type check and build optimized bundle
npm run build

# Preview production build locally
npm run preview
```

- **Frontend**: React 19, TypeScript, React Router 7
